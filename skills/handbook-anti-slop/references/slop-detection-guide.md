# Slop 检测方法论（出自李韭二《什么他妈的叫他妈的人味》）

本文是 `handbook-anti-slop` 技能的**方法论依据**。Skill 是做法，本文件是「为什么这么做」的原理。

## 一、人味的本质

人味 ≠ 风格修饰。人味 = **偏离群体均值的结构化能力**。

AI 写作"没人味"的根本原因不是某个具体特征，而是 AI 倾向收敛到训练分布的中心；写方只要走大模型路径，就天然把人味推向中心化。一个章节里所有的可替换特征（句长均匀 / 高频 AI 词 / 无差别模板），都是中心化的表征。

## 二、两条路

### 减法（删 AI 痕迹）

- 删连接词 / 破折号
- 打散总分总模板
- 替换 AI 高频词（delves / tapestry / vibrant 等）
- 拉高句长方差（burstiness）

**作者判定：拥挤、易过期、只骗检测器、触发古德哈特定律。** 检测器特征一被当优化目标，写作生态会立刻学会反过来绕开它；这条路是猫鼠游戏。

### 加法（加人）

- **具体度**（concreteness）：具体名词 / 精确数字 / 真实地名 / 精确细节。避免名词化（operate → operation）。可参照 MELD-SCH 中文具体度词库（9877 双字词）。
- **判断浓度**（stance / engagement）：模糊限制语 / 增强语 / 态度标记 / 自我提及。可用 Hyland 2005 介入标记，或 Martin & White 2005 评价理论（态度 / 介入 / 级差）。
- **在场感**（presence / 不可替换性）：写只有你会知道、会这么说的具体锚点；不使用可替换的「我认为这很重要」，而用「我昨天在杭州被这个 bug 坑了三小时」。

**作者主张：几乎没人走的路，对检测器免疫**。Jakesch 等实验证伪了"数第一人称"的捷径——真在场 = 把作者换成任何人这句话不成立。本质上，在场感是具体度的不可替换子集。

## 三、四层离群（人味=偏离群体均值的结构化能力）

| 层 | 内容 | 生产侧原则 |
|---|---|---|
| 虚词层（身份） | 功能词 z 向量 | 保护自己的「的/了/而」频率，别让 AI 润色推到模型中心 |
| 信息层（节奏） | 信息率 | 按语篇结构调制信息率，局部平滑、全局起伏；不是处处均匀如空调 |
| 语义层（内容） | 语义锚点 | 落点低概率语义锚点：具体 / 判断 / 在场感 |
| 社会层（生态） | AI 词汇生态 | 抵抗 AI 词汇渗入与自我审查拉力，保持方差 |

检测器只看见最浅的虚词层；真正的人味在更深三层的偏离里。

## 四、三条红线（写作型 AI 的宪法）

1. **不可优化原则**：把检测器特征当优化目标，指标立刻崩塌（古德哈特定律）。
2. **镜子而非靶子**：诊断工具只向作者提问、把锚点织回去，绝不接自动改写。
3. **诚实边界**：工具不替作者造数字、编经历——那是造假的起点。

## 五、预注册实验的提醒

- **越有人味的文本越易被润色杀伤**：口语声口浓文本润色漂移高近 8 成。提醒作者重点保护。
- **洗掉的人味救不回来**：润色前留原稿真值；工具只守"不生造"底线不够，须问出正确问题（要回真锚点）。
